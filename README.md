# HIRAETH — THE TOWER OS V2.4.2｜單主視窗導覽試玩版

這是根據使用者於 2026-10-30 提出的介面調整製作的 **獨立試玩版本**。它以 V2.4.1 設定更新版為基礎，**保留全部新世界觀文案、原本的入職培訓及駭入劇情**，主要改動的是正式工作桌面的操作體驗。網站使用純 HTML、CSS、JavaScript，可本機開啟或部署至 GitHub Pages。

## V2.4.2 這次的變更

1. **單一大型主視窗**：工作桌面只開啟一個主要閱讀視窗。郵件、文件、人員名錄之間跳轉，不再疊加多個小視窗。原本的桌面、圖示與工作列仍保留。
2. **左上角返回**：開啟郵件、文件、人物檔案後，使用標題列左上角「← 返回」回到上一層。根頁面的按鈕為「← 返回桌面」；右上角 `×` 也能直接關閉並返回工作桌面。`Esc` 鍵也支援返回（輸入框聚焦時除外）。
3. **完整導覽路徑**：例如「工作桌面 → 內部郵件 → 單封郵件 → 關聯文件」，返回時會保留上一頁資料與人物的分頁狀態。
4. **柔和過場動畫**：開啟主視窗時淡入、輕微放大及移動；進入下一層內容從右側淡入，返回上一層從左側淡入；切換分頁有短淡入動畫。背景加入輕微模糊與遮罩。
5. **手機版單頁閱讀**：在較小螢幕使用幾乎全螢幕的主視窗，避免浮動視窗重疊。並支援系統的 `prefers-reduced-motion` 選項及工作桌面「減少介面動畫」設定。

### 保留的內容與功能

- 入職流程：工號登入、初次條款、七個新人導覽模組、十題綜合測驗、十二條最終保密協議及完成確認。
- 工作系統：6 封內部郵件、15 份工作文件、6 位人員索引（薩維恩與綺靈澤有較完整資料），政府與塔的官方入口、日程、個人資料與系統設定。
- 2026-10-30 移交的圍牆／營區、法定入編、退休、完全結合與綺靈澤現行職能等設定更新。
- 首次進入正式工作系統時的異常駭入與 4 份外部敘事紀錄；快速預覽模式仍跳過首次駭入。
- 人物立繪由 `content/workstation.js` 的 `people[].image` 指定相對路徑，例如 `assets/characters/savien.png`。

## 試玩方式

1. 解壓縮 ZIP，**保留 `css/`、`js/`、`content/`、`assets/` 的資料夾結構**，不要把檔案全部攤平。
2. 在 Chrome 或其他現代瀏覽器開啟最外層的 `index.html`。
3. 選擇「快速預覽 V2.4.2 工作桌面」直接測試，也可以選擇「登入工作終端」完整體驗故事。
4. 試著依序點選「內部郵件 → 新進人員｜營區生活與休假指引 → 閱讀營區生活與休假指引」，再連續按左上角「返回」。此時應只有一個主視窗。
5. 試著選擇「人員名錄 → 綺靈澤 → 關聯文件 → 某份文件 → 返回」，應回到剛才的綺靈澤「關聯文件」分頁。

## 進度與部署提醒

- 本測試版仍使用 `hiraeth-tower-v24-preview` 進度儲存鍵，不會直接覆寫原始 V2.2 的儲存鍵。
- 自訂工號僅為模擬身份，不是真實登入。資料留在瀏覽器本機，不跨裝置同步。
- 目前公開的正式 `Hiraeth` GitHub Pages **不會因解壓此 ZIP 而改變**。正式發布前請先備份線上版本並完整驗收入職流程。
- GitHub Pages 是公開的靜態網站，技術使用者仍可能查看前端原始資料。尚未準備公開的作者秘密設定不要放進 `content/`。
- 本版本刻意取消了閱讀視窗的自由拖曳、多視窗堆疊和最小化，以提升沉浸式閱讀與手機體驗。正常桌面與特殊駭客視窗仍彼此區分。
