# HIRAETH — THE TOWER / FIRST DAY · V2.2

擎嵐獨立哨兵嚮導 AU：互動式「塔新進人員入職系統」。這是可在 GitHub Pages 運作的純靜態網站，不需要資料庫、真實登入或外部套件。

## 直接試玩

1. 解壓縮 ZIP。
2. **直接開啟 `index.html`**（在 Chrome、Safari、Firefox 或 Edge 均應可使用）。
3. 預設工號 `Q008`，可以改為任意 2–20 位英文字母／數字／`-`。
4. 選填姓名；閱讀初次保密須知並確認。
5. 依序完成 Module 01–06，每個章節都有多個閱讀分頁。Module 01 第三節可點擊**政府／塔**圖標，開啟各自的模擬官方網站；兩者都瀏覽後才能完成該單元。
6. Module 07 是真實桌面的 **STEP 01–05** 框選教學；完成後進入統一 10 題測驗（8/10 通過，可重考）。
7. 閱讀 12 條正式保密協議，勾選兩項聲明並輸入登入時的工號作為**模擬電子簽署**。
8. 確認所有培訓事項後，點「進入工作系統」。**直到這個時間點**才會首次出現異常通訊與可選擇閱讀的劇透資料。
9. 右下角「重置體驗」可以清除本機進度。

> 工號只是敘事體驗的識別代號，並非真實登入。網站不要求密碼，也不會傳送工號或個資至伺服器。進度使用瀏覽器本機儲存（localStorage），同裝置同瀏覽器重新開啟可以接續；無痕模式可能不保存。

## GitHub Pages 部署

1. 建立 GitHub 儲存庫（例如 `hiraeth`）。
2. 上傳本資料夾內的檔案到儲存庫**根目錄**。請確認 GitHub 根目錄可以直接看到 `index.html`、`css/`、`content/`、`js/`、`assets/`。
3. GitHub → **Settings → Pages** → Build and deployment → **Deploy from a branch**；選 `main` 與 `/(root)`，儲存。
4. 網站通常會出現在 `https://USERNAME.github.io/hiraeth/`。此專案使用相對路徑，可以部署至子路徑。

## 如何編輯

- `content/training.js` — 七個單元的完整文字、十題測驗、兩份條款、兩個官網頁面、駭入後的外部檔案；以 JavaScript 物件形式編輯。
- `css/style.css` — 顏色、字體、排版、網頁視窗與桌面教學效果。
- `js/app.js` — 培訓進度、切頁、考試、電子簽署、桌面與事件觸發。
- `assets/tower-atmosphere.jpg` — 工作桌面背景（可自行用新圖片替換，保留檔名即可）。交接包圖片是**氣氛參考，非已確認的世界設定**。

## 作者設定與劇透

- 教材中「塔」對**奇美拉**的敘述是世界內的**官方宣傳**，不代表客觀事實。已確認的真相留在 `leak` 資料內，正常流程直到工作桌面開啟才會顯示。
- GitHub Pages 上線後，所有前端資料**本質都是公開可檢視的**；劇透門檻僅為敘事設計，不是安全保密機制。**不要把真實私人草稿放入公開儲存庫。**
- 官方網站名稱、文件編號、員工流程、案例等仍屬網站形式提案，未自動成為 AU 正式設定。
- 讀者可以在最後選擇關閉駭客訊息；之後可透過工作桌面的「外部資料」圖示自行查看。

## 無資料庫、無追蹤

所有流程均在使用者瀏覽器裡進行；異常連線是視覺敘事，不會進行實際駭客行為、安裝軟體、開啟系統層級的彈窗或讀取訪客電腦。
